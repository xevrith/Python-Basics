# Python Basics

A structured Python learning repository containing beginner-to-intermediate examples and practice exercises. Topics are arranged in a suggested learning order, with numbered folders and files to make progression easier to follow.

The goal is to build strong fundamentals through writing, testing, debugging, and explaining code independently.

## Getting Started

### Requirements
- Python 3
- VS Code or another code editor
- A terminal

Most examples use only Python's standard library.

### Run an exercise

Run commands from the repository root. For example:

```bash
python "15_Variables/01_create_and_display_variables.py"
```

On some systems, use `python3` instead of `python`. Run one exercise at a time, especially when it asks for terminal input.

## Recommended Study Method

1. Read the task and identify the Python concept being practiced.
2. Predict the output before running the file.
3. Solve the task without copying a completed solution.
4. Test normal, boundary, and invalid inputs.
5. Explain your logic in plain language.
6. Rebuild the solution from a blank file later.

Do not measure progress by how many files you execute. Measure it by whether you can solve the same problem independently.

## Important Notes

- This is a learning repository, not a production-ready Python package.
- Some files are examples or attempts and may intentionally be incomplete. Check the task description before assuming every file is a finished solution.
- The folder numbering is a suggested study sequence. New topics may be added as the learning path expands.
- Do not treat running a script successfully as proof that its logic handles every edge case.
