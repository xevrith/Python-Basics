# Python Basics

A structured Python learning repository containing beginner-to-intermediate examples and practice exercises. Topics are organized into numbered folders to support a clear learning progression.

The goal is to build strong fundamentals through writing, testing, debugging, and explaining code independently.

## Folder Guide

- **01_Operators:** Arithmetic, assignment, swapping, comparison, identity, logical truthiness, and membership checks.
- **02_Strings:** String cleanup, indexing, slicing, reversing, replacements, extraction, case conversion, formatting, and validation.
- **03_Lists:** List access and updates, adding/removing items, sorting, nested lists, filtering, comprehensions, and practical exercises.
- **04_Tuples:** Tuple creation, unpacking, indexing, slicing, membership, count, index, and length.
- **05_Sets:** Unique values and set-based inventory exercises.
- **06_Dictionaries:** Dictionary basics, updates, nested dictionaries, inventory data, and frequency counting.
- **07_Loops and 08_Nested_Loops:** Iteration, counting, totals, string processing, patterns, repeated attempts, and sequence exercises.
- **09_Functions:** Function definitions, arguments, return values, validation, calculations, and reusable logic.
- **10_OOP:** Classes, objects, constructors, attributes, methods, encapsulation, and inheritance.
- **11_Exception_Handling:** Handling invalid input, runtime errors, and validation exceptions.
- **12_Lambda:** Anonymous functions for calculations, comparisons, transformations, and use with map, filter, and sorted.
- **13_Comprehension:** Compact collection-building exercises using conditions and transformations.
- **14_Regular_Expressions:** Pattern matching with `search`, `findall`, `fullmatch`, character sets, anchors, greedy and non-greedy quantifiers, and regex flags (`DOTALL`, `IGNORECASE`, and `MULTILINE`). Includes four practice files with worked answers.
- **15_Variables:** Beginner tasks covering variable creation, salary calculations, swapping values, input conversion, and simple bills.
- **16_Conditional_Statements:** Beginner tasks covering number classification, even/odd checks, eligibility, grades, and discounts.
- **17_File_Handling:** Six practice files covering text file read/write, append operations, record analysis, expense tracking, attendance reports, and word counting. Each file includes tasks and worked answers.

## Getting Started

### Requirements

- Python 3
- VS Code or another code editor
- A terminal

Most examples use only Python's standard library.

### Run an exercise

Run commands from the repository root. For example:

```bash
python "17_File_Handling/04_expense_tracker_practice.py"
```

On some systems, use `python3` instead of `python`. Run one exercise at a time, especially when it asks for terminal input.

## Recommended Study Method

1. Read the task and identify the Python concept being practiced.
2. Predict the output before running the file.
3. Solve the task without copying a completed solution.
4. Test normal, boundary, and invalid inputs.
5. Explain your logic in plain language.
6. Rebuild the solution from a blank file later.

Do not measure progress by how many files you execute. Measure it by whether you can solve the same problem independently.

## Important Notes

- This is a learning repository, not a production-ready Python package.
- Some files are examples or attempts and may intentionally be incomplete. Check the task description before assuming every file is a finished solution.
- The folder numbering is a suggested study sequence. New topics may be added as the learning path expands.
- Files created by exercises (such as `expenses.txt` or `attendance.txt`) are generated in the current working directory when the script runs.
- Do not treat running a script successfully as proof that its logic handles every edge case.
