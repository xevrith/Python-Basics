# Python Basics

A structured collection of Python learning exercises, examples and small problem-solving tasks. The repository is arranged in a suggested beginner-to-intermediate learning sequence. Folder numbers show the order in which to study the available topics; file numbers show the suggested order within each folder.

## Learning Roadmap

| Order | Folder | What to learn |
| ---: | --- | --- |
| 01 | `01_Operators` | Arithmetic, assignment, comparison, logical and membership operators |
| 02 | `02_Strings` | String indexing, slicing, methods, transformations and validation |
| 03 | `03_Lists` | List operations, nested lists, filtering, sorting and comprehensions |
| 04 | `04_Tuples` | Immutable sequences, indexing, slicing and tuple methods |
| 05 | `05_Sets` | Set-based data handling |
| 06 | `06_Dictionaries` | Key-value data, updates, nested dictionaries and counting |
| 07 | `07_Loops` | For loops, while loops, iteration, counting and patterns |
| 08 | `08_Nested_Loops` | Nested while loops, repeated attempts and pattern exercises |
| 09 | `09_Functions` | Reusable logic, parameters, return values and problem-solving |
| 10 | `10_OOP` | Classes, objects, attributes, methods, encapsulation and inheritance |
| 11 | `11_Exception_Handling` | Handling invalid input, runtime errors and validation exceptions |

**Study tip:** Complete the files in numerical order. Before running each file, predict the output. Then run it, explain the result in your own words, and modify the inputs to test edge cases. The numbering is a suggested sequence, not a guarantee that every exercise is equally easy or fully complete.

## Getting Started

### Requirements
- Python 3 installed.
- A code editor such as VS Code, or a terminal.
- No third-party packages are required for most examples; individual files may have their own requirements.

### Run an exercise
1. Open or clone this repository.
2. Open the repository folder in VS Code.
3. Open a numbered Python file.
4. Open the terminal at the repository root.
5. Run one file at a time. For example:

```bash
python "01_Operators/01_arithmetic_floor_division_modulo_and_power.py"
```

On some systems, use `python3` instead of `python`. Some exercises request user input in the terminal.

## Recommended Practice Method

1. Read the filename and identify the concept.
2. Read the code before executing it.
3. Write down what you expect the output to be.
4. Run the file and compare the actual output.
5. Change the input values and test different cases.
6. Explain the logic without looking at the code.
7. Rebuild the same solution from a blank file after a short break.

Do not simply run every file and move on. The objective is to understand and reproduce the logic independently.

## Important Notes About the Exercises

- The repository is a learning workspace, not a polished Python package or a collection of production-ready applications.
- Existing Python source code was retained during this reorganization. The work in this update changes folder names, file names, numbering and documentation; it does not rewrite the exercises.
- Some exercises are intentionally or unintentionally incomplete and some may contain syntax or logic mistakes. For example, the revenue-extraction exercise is incomplete, and a few filenames explicitly include words such as `attempt` or `incomplete` where that distinction matters.
- The numbering does not mean that every file has been tested or corrected. Treat each exercise as practice material and verify it yourself.
- Some common Python fundamentals, such as variables, input/output and conditionals, are used inside exercises but do not yet have dedicated folders in this repository.
